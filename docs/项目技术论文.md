# 面向讲解视频的结构化知识提取框架：板书 OCR × 语音听译 × 术语校正 × 关键帧分析

**作者**：DeeLiuSol  
**日期**：2026-08-12  
**项目**：[video-course-ai](https://github.com/DeeLiuSol/video-course-ai)

## 摘要

大量高质量讲解视频（教学课、直播、讲座）存在**无字幕、有板书、专业术语密集**的特点，通用语音识别（ASR）对领域术语识别弱，通用 OCR 又不处理视频时间轴与板面滚动，导致视频内容难以结构化、可检索。本文提出一套**讲解视频 → 结构化知识**的提取框架：融合**板书 OCR**、**语音听译**、**领域术语词典三层校正**与**关键帧/板面分析**，并引入**跨帧共识投票**与**交叉对比**两项机制，分别解决单帧 OCR 整行认错与信息源互校问题。框架已实际应用于命理课程（八字取财方式讲解，3 个视频全量交付），同一流程可扩展到中医、法律、金融等任何领域。实验表明：板书从 60 段滚动中间态收敛为 6-8 个稳定板面；跨帧共识投票将单帧 OCR 整行认错（正确版 14 帧 vs 垃圾版 1 帧）自动纠正；案例主题经交叉对比全部正确归类。

**关键词**：视频内容提取；OCR；语音识别；术语词典校正；关键帧分析；交叉验证

## 1 背景与问题

### 1.1 应用场景

讲解视频是知识传播的重要载体，典型形态有三类：

| 形态 | 特点 | 挑战 |
|------|------|------|
| 无字幕 + 有板书 | 教学/直播课，板书随讲解逐行累积 | 需 OCR 板书 + ASR 听译双路 |
| 无字幕 + 无板书 | 纯口播/讲座 | 纯 ASR，术语误听严重 |
| 有字幕/文稿 | 平台自动字幕或原始稿件 | 需解析字幕并校正，不必 ASR |

### 1.2 四个核心难点

1. **专业术语识别弱**：通用 ASR（whisper 等）对领域术语（命理"驿马/食伤"、中医"穴位/方剂"）系统性误听（如"驿马"→"异码"、"食伤"→"时尚"），仅靠通用模型无法解决。
2. **板面滚动/擦写中间态**：视频板面随讲解滚动、逐行弹出、被新内容覆盖。若按"每次变化截帧"，一个知识点会产生几十个中间态（实测 60 段），板面文字残缺、重复、错位。
3. **单帧 OCR 整行认错**：OCR 对某一行可能整行认错（如 `身浊灼吐…` 实际应为 `身强财旺，且日主能够三合六合暗合住财星`）。字符级纠错与"跨帧取完整版"（字符串相似度匹配）均无法修复——错误串与正确串完全不同。
4. **信息源孤立**：板面、语音、案例、字幕各为独立信号，未互相印证。而讲解视频中**主讲人口述紧扣板书、案例紧扣当前主题**，信息源之间天然存在强关联。

## 2 系统设计

### 2.1 总体架构

```
┌──────────────┐   ┌──────────────────┐   ┌─────────────────────┐
│  输入视频      │   │  内容提取层        │   │  词典校正层           │
│  无字幕有板书   │──▶│  ├ 抽帧+OCR(板书)  │──▶│  V1 精确映射          │
│  无字幕无板书   │   │  ├ ASR 听译(语音)  │   │  V2 上下文规则        │
│  有字幕/文稿   │   │  └ 字幕/文稿解析   │   │  V3 组合术语          │
└──────────────┘   └──────────────────┘   └─────────────────────┘
                                              │
                              ┌───────────────┴──────────────┐
                              ▼                              ▼
                    ┌──────────────────┐            ┌──────────────────┐
                    │  关键帧/板面分析   │            │  报告生成         │
                    │  稳定板面挑选      │            │  知识点+案例       │
                    │  跨帧共识投票      │            │  +主讲人口述      │
                    └──────────────────┘            └──────────────────┘
```

### 2.2 板书提取与稳定板面挑选

**问题**：按时间片段平铺会得到 60 段中间态。  
**方案**：对每个分段计算"板书完整度分数"（干净长行总长度，先经排盘/噪声分离），取**局部最高点**作为稳定板面候选——板面在讲解间隙会保持完整，滚动/擦写瞬间分数低。再经内容去重（重叠 ≥50% 视为同一板面）与案例帧噪声过滤，将 60 段收敛为 6-8 个稳定板面，复现人工"挑好时机截图"的效果。

同时实现**板书/非板书分离**：黄底排盘、字幕、新闻片段等混入 OCR 的非板书内容，通过混合行拆分（板书+排盘 token 拆开保留板书侧）与排盘模式识别（天干+十神、日期年份、节气/农历/流年等）独立成 `case_lines`，不污染正文。

### 2.3 语音听译与领域术语词典三层校正

**问题**：通用 ASR 对领域术语系统性误听。  
**方案**：采用 whisper.cpp large-v3-turbo（贪心解码，不依赖 torch，AMD CPU 可跑），叠加**领域术语词典三层校正**：

- **V1 精确映射**：`asr_correction_map`，误听词→正确词，长词优先单遍替换（如"驿马"→"异码"）
- **V2 上下文规则**：`context_rules`，regex lookbehind/lookahead，仅当词出现在特定上下文才替换，避免误伤普通语料
- **V3 组合术语**：多字符组合修复

词典为领域专属（命理版 194 条映射 + 190 条上下文规则，另有 `fixed_phrases` 194 条完整搭配保护、`dizhi_relations` 地支关系知识表），中医/法律/金融各建各的词典，框架层通用。

**多形态适配**：无字幕有板书 → OCR+ASR；无字幕无板书 → 纯 ASR；有字幕/文稿 → `parse_subtitles.py` 直接解析（.srt/.vtt/.ass/.txt）为标准分段 JSON，复用同一校正与下游流程。

### 2.4 跨帧共识投票（关键创新）

**问题**：单帧 OCR 整行认错，字符串相似度补全无法修复（错误串与正确串字符完全不同）。  
**方案**：同一知识点要点在多个帧中出现，正确版出现次数远多于单帧误读。据此：

1. 将每个编号要点行按**槽位**归类——槽位 = 同编号 + 同主题块内共同出现的其它要点（coset 相交）。槽位按编号 + 主题块限定，防止同主题 1/2/3 点互相覆盖。
2. 对槽位内所有帧的版本做**投票**，取出现次数最多的版本（≥3 帧）作为共识。
3. 渲染板面时用共识版替换单帧版本。

**实例**：某帧 OCR 输出 `2、身浊灼吐，日口土能吸二口八口阳口住财生`（1 帧），正确版 `2、身强财旺，且日主能够三合六合暗合住财星` 在 14 帧出现——投票自动压回正确版。

### 2.5 交叉对比（Cross-Reference）

**核心洞察**：讲解视频中**板面文字是讲解的"可靠锚点"**——主讲人口述紧扣板书、案例紧扣当前主题、字幕/文稿是可靠文本源。信息源互校：

- **案例 ↔ 板书主题**：用干净板书原文构建"第X种→要点"参照表；案例按"时间窗内板行 + 主讲人口述"与参照表交叉比对，命中要点最多的主题即归属。替代硬编码关键词猜主题，案例归类全部正确。
- **板书原文 ↔ ASR 听译**：主讲人念的多是板书原句，用板书参照纠正 ASR 误听（如"乱合→乱和"、"肉体→陆体"），大幅减少人工后处理。
- **字幕/文稿 ↔ 词典**：有字幕/文稿的视频，文本直接作为校正源并可反哺领域词典，词典越用越准。

### 3.1 模块清单

## 4 与同类方法对比

| 方法 | 板书 OCR | 领域术语 | 板面中间态 | 单帧认错 | 信息源互校 |
|------|---------|---------|-----------|---------|-----------|
| 通用 ASR 转写工具（如 whisper 直转） | ✗ | ✗ 误听严重 | — | — | ✗ |
| 通用 OCR 工具（截图 OCR） | ✓ 但不含时间轴 | 部分 | ✗ 不管 | ✗ | ✗ |
| 商用音视频转写（通义听悟等） | ✗ | 弱 | ✗ | ✗ | ✗ |
| 人工蒸馏 Skill（如纯人工整理课程） | — | ✓ 但人工成本高 | — | — | ✓ 但不可扩展 |
| **本框架** | ✓ 含时间轴+稳定板面 | ✓ 词典三层校正 | ✓ 收敛 60→8 | ✓ 共识投票 | ✓ 板面作锚点 |

**核心优势总结**：

1. **领域术语可控**：词典驱动三层校正，术语准确率不依赖通用模型；词典领域可换（命理/中医/法律）
2. **板面质量自动化**：稳定板面挑选 + 共识投票，达到人工"挑好时机截图"的效果，无需人工介入
3. **信息源互校**：板面作可靠锚点，反哺案例归类与 ASR 纠错——这是同类工具没有的
4. **多形态适配**：无字幕有板书 / 无字幕无板书 / 有字幕 / 有文稿，四态统一到标准数据流
5. **可扩展为 Skill 地基**：产出结构化知识（板书原文/知识点/案例/口述），是构建领域问答 Skill 的内容基座

## 5 讨论与未来工作

**讨论**：
- 本框架的精度上界受限于 OCR/ASR 引擎：rapidocr 对个别字整行认错（缺"象"、比切=比劫等）时，跨帧补全只能补"缺"不能纠"错"，需靠共识投票或多帧覆盖；全量消除需更强视觉模型（如 Qwen-VL）重读稳定页帧。
- 板面是累积式的（旧内容不消失、新内容叠加），时间维度无清晰翻页边界——按"稳定板面"而非时间分段是本框架的关键判断。

**未来工作**：
1. **批量扩展内容基座**：处理更多视频，积累领域知识库（当前 3 个视频 → 计划批量）
2. **跨领域验证**：扩展到中医师讲解视频（有字幕/文稿，直接走字幕解析路径）
3. **蒸馏层 + Skill 封装**：内容地基足够后，将结构化知识蒸馏为 reference 模块，封装领域问答 Skill
4. **更强视觉模型**：接入 Qwen-VL 等视觉大模型重读关键帧，进一步提升 OCR 边界字符准确率
