# 如何把讲解视频，变成可检索的知识？

## 我们做了什么

做了一套"讲解视频 → 结构化知识"的提取框架。输入一段视频，就能自动输出：

- 板书上的完整知识点文字
- 主讲人的语音听译稿
- 每个知识点对应的案例
- 主讲人对每个案例的点评

也就是说，把一个半小时的讲课视频，变成一篇结构清晰、可检索、可提问的知识文档。

这套框架已经用在命理课程上，跑通了 3 个视频。但它的底层能力是通用的——中医、法律、金融，任何"讲解 + 板书 + 专业术语"的视频都能用。

## 为什么这么做

因为讲解视频有个老大难的问题：**内容都很好，但拿不出来**。

第一个难点，**无字幕**。只能靠语音识别。但语音识别对专业术语天生就弱——"驿马"被识别成"异码"，"食伤"被识别成"时尚"。一节课下来，术语全错，没法用。

第二个难点，**有板书**。知识都写在板面上，但板面是滚动的、逐行弹出的、被新内容覆盖的。如果按"每次变化截一帧"，一个知识点会截出几十个片段，大部分是残缺的、重复的中间态。

第三个难点，**单帧识别会整行认错**。比如某一帧，OCR 把一行字认成了完全不相干的另一句。字符级纠错救不回来，因为错的字和对的字完全不一样。

第四个难点，**各信息源互相孤立**。板面、语音、案例、字幕，各自是独立的信号，谁也不管谁。但实际上它们强相关——主讲人念的就是板面上的字，讲的案例就对应当前的主题。

所以，通用工具搞不定，因为这是四个叠加的问题。

## 怎么做的：四个机制

针对这四个难点，我们设计了四个机制。

第一个，**稳定板面挑选**。给每个片段算一个"板书完整度分数"，取分数最高的那些瞬间作为稳定板面。原理很简单：讲解间隙板面是完整的，滚动和擦写瞬间分数低。于是 60 个滚动片段，收敛成 8 个稳定板面。这就相当于自动复现了"人工挑好时机截图"。

第二个，**跨帧共识投票**。同一句话在多个帧里都出现，正确的那版出现次数一定远多于认错的那版。所以把同一知识点要点按"编号 + 主题"归到一类，对类内所有帧的版本投票，取多数。实测：某一帧把"身强财旺，且日主能够三合六合暗合住财星"认成了"身浊灼吐……"，只有 1 帧错，另外 14 帧都是对的，投票自动把错的压回对的。

第三个，**领域术语词典三层校正**。通用语音识别对术语弱，我们就用词典去补。词典分三层：精确映射（误听词 → 正确词）、上下文规则（只在特定语境才替换，避免误伤普通话）、组合术语（多字组合修复）。词典是领域专属的——命理一套、中医一套、法律一套，框架本身是通用的。

第四个，**交叉对比**。这是我们认为最有价值的一点。核心洞察是：**板面文字是讲解的"可靠锚点"**。既然主讲人念的是板面上的字，那板面就能反过来校准语音。用板面原文做参照，案例自动归到正确主题；用板面原文做参照，还能纠正语音里的误听。信息源之间互相印证，而不是各干各的。

另外还兼容四种视频形态：无字幕有板书、无字幕无板书、有字幕、有原始文稿。有字幕的不用跑语音识别，直接解析字幕就行。

## 这么做的好处

一句话：**把人工整理的工作，自动化了**。

具体讲：

- 之前要从视频里抠出知识点，得人工看一遍、抄一遍、归类一遍。现在跑一遍管线，自动产出。
- 板面质量能到"人工挑好时机截图"的水平，不用人肉盯。
- 案例自动归类到正确主题，不用猜。
- 术语准确率不依赖通用模型，词典越用越准——有字幕的视频还能反哺词典。
- 产出是结构化知识，是将来做领域问答助手（AI Skill）的内容地基。

## 和其他方案的对比

市面上有几类做法，我们都比过：

**通用语音转写工具**（比如直接拿 whisper 转）：只解决"有没有文字"，不解决"术语对不对"。命理术语全错，没法直接用。

**通用截图 OCR 工具**：能识别板面，但不处理时间轴，不处理滚动中间态，不处理单帧认错。60 个残缺片段照样给你 60 个。

**商用音视频转写平台**：有字幕功能，但领域术语弱，没有板书 OCR，不做信息源互校。

**人工整理**：质量最好，但一节课要人盯一小时，不可扩展。几十上百个视频就做不动了。

**我们的框架**：板书 OCR 带时间轴和稳定板面，术语词典三层校正，跨帧共识投票修单帧认错，板面做锚点交叉互校。而且代码开源，词典领域可换。

总结成一句话：**别人是"通用"的，我们是"领域可定制 + 自动化 + 信息互校"的**。

## 未来

接下来会做几件事：批量处理更多视频，把内容地基铺厚；扩展到中医等其它领域验证通用性；内容够了以后，封装成领域问答助手；接入更强的视觉模型，进一步提升 OCR 边缘字符的准确率。
